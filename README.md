# Лабораторна робота №1 — Робота в інтегрованому середовищі Visual Studio C++ 2010

**Варіант 4**

## Умова задачі

Задано `x = 0.48·№`, `y = 0.47·№`, `z = -1.32·№`, де № — номер варіанту (4).
Отже базові дані: `x = 1.92`, `y = 1.88`, `z = -5.28`.

Формули варіанту 4:

```
a[x,y,z,b] = y² + (z/x² + sin²b) / | (x²+y) / (z + x³/3) | - ln|x²+z|

b[x,y,z]   = | (x+y)/|z|^0.6 + sin²( (x+z²)/(2x+y) ) |^(1/3) - z·e^((x²-y)/(1+z))
```

`b` обчислюється першим (функція `a` залежить від значення `b`).

> Примітка: при `x = 0` функція `a` не визначена (ділення на `x²`), тому таблиця
> у Завданні 2 позначає цю точку як "не визнач.".

## Діаграма класу

```
ZavdClass
- a : double
- b : double
+ ZavdClass()
+ ~ZavdClass()
+ Fn_a(x, y, z) : void
+ Fn_b(x, y, z) : void
+ Faktr(n) : double
+ geta() : double
+ getb() : double
```

## Збірка та запуск

Потрібен компілятор із підтримкою C++17 (g++, clang++ або MSVC).

### Linux / macOS (g++)

```bash
g++ -std=c++17 -Wall -o task1 task1_main.cpp ZavdClass.cpp
g++ -std=c++17 -Wall -o task2 task2_main.cpp ZavdClass.cpp

./task1
./task2
```

### Windows (Visual Studio)

1. Створити новий проєкт **Console App (C++)**.
2. Додати `ZavdClass.h`, `ZavdClass.cpp` та один із файлів `task1_main.cpp` /
   `task2_main.cpp` (як `main.cpp`) до проєкту.
3. Зібрати (`Ctrl+Shift+B`) і запустити (`Ctrl+F5`).
